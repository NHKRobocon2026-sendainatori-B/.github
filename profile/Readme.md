# 高専ロボコン2026  仙台高専名取キャンパスBチーム　「回雑巾」

## ロボットの概要
  雑巾を回転させ、フリスビーのように射出するロボットです。<br>
  足回りには独立ステアリングを採用し、Raspberry Pi 4上のROS2、stm32、スマートフォンコントローラーを組み合わせて制御しています。
